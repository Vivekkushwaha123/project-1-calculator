# Interactive Calculator & Unit Converter

A beginner-friendly Python CLI (Command-Line Interface) program that handles basic arithmetic operations, currency/unit conversions, and safe input validation.

Built as part of **Project 01** for the **InternCircle Python Programming** track[cite: 1].

---

## 🚀 Features

- **Basic Arithmetic:** Addition, subtraction, multiplication, and division[cite: 1].
- **Safe Input Validation:** Prevents crashes if a user enters letters, empty text, or non-numeric input.
- **Zero-Division Protection:** Handles division by zero gracefully with a user-friendly error message[cite: 2, 3].
- **Unit Conversions:** 
  - Kilometers to Miles[cite: 1]
  - Celsius to Fahrenheit[cite: 1]
  - Kilograms to Pounds
- **Interactive Menu Loop:** Keeps the program running until the user explicitly chooses to exit.
